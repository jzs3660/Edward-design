# Example deck brief

Create a concise two-slide English presentation for an operations review.

- Audience: department leads.
- Purpose: introduce a repeatable review rhythm.
- Story: open with the thesis, then explain two operating principles.
- Output: HTML for the smoke test.
- Branding: use generic placeholder branding and `example.com`.
- Content: do not introduce customer names, financial metrics, or unsupported claims.
- Assets: no custom images are required.
